## 图
极大的连通子图称为**连通分量**，在有向图中，若任意两点都存在两个方向的有向路径，称为强连通；只要求存在某个方向的有向路径时，称为弱连通。

### 存储结构
邻接矩阵是 $|V| \times |V|$ 的二维数组，保存对应的有向边的权值；邻接表是每个顶点存一张出边表。

十字链表即同时组织邻接表与逆邻接表：

```cpp
struct ArcBox {
    std::size_t tailvex; // 弧尾 u
    std::size_t headvex; // 弧头 v
    ArcBox* tailnextarc; // 下一条同尾弧
    ArcBox* headnextarc; // 下一条同头弧
    int info;            // 权值
};

struct VexNode {
    ArcBox* firstin = nullptr;  // 第一条指向本顶点的弧
    ArcBox* firstout = nullptr; // 第一条从本顶点出发的弧
};
```

### 遍历
深度优先搜索是：记录已访问过的节点；递归地遍历一个节点连边的所有节点。广度优先搜索使用队列，同理。

对于有向无环图，我们定义**拓扑序列**：如果存在 $v_i$ 到 $v_j$ 的箭头，则序列中 $v_i$ 在 $v_j$ 之前。拓扑排序的方法是：重复进行 ① 选出一个入度为 0 的顶点并输出； ② 删除图中该顶点和所有以它为起点的边。如果结束时还有顶点没有输出，说明有向图有环。

### 最短路径
单源最短路径问题是指，给定源 $s$，找到到所有其它各顶点的最短路径。Dijkstra 算法维护一个已经确定最短距离的集合 $S$，及中间只经过 $S$ 的路径（“特殊路径”）中的最短路径长度。最开始 $S$ 只含有 $s$，经过 $S$ 的路径只有连的边，之后每次从 $V - S$ 中取出一个最短特殊路径长度最小的顶点，将它加入 $S$，然后更新。如果使用数组维护最短特殊路径长度，则时间复杂度 $O((|V| + |e|) \log |E|)$；使用最小堆则时间复杂度 $O(|V|^2)$.

另一个问题是所有顶点对之间的最短路径问题。Floyd 算法迭代地得到 $\mathrm{adj} _{i,j}^{(k)}$ 是从 $v _i$ 到 $v _j$，中间只经过 $v _0, \dots, v _{k-1}$ 的最短路径长度。时间复杂度 $O(n^3)$：

$$\mathrm{adj} _{i,j}^{(k)} = \min \set{\mathrm{adj} _{i,j}^{(k-1)}, \mathrm{adj} _{i,k-1}^{(k-1)} + \mathrm{adj} _{k-1,j}^{(k-1)}}$$

### 最小生成树
最小生成树是指连接 $G$ 的所有顶点的树，且权值总和最小。

Prim 算法维护一个顶点集 $U$ 和最小生成树的边集 $T$，初始时任取一个顶点，$U = \set{u_0}$，然后每次找 $(u, v) \in U \times U - V$ 权值最小，将这条边加入 $T$，然后将 $v$ 加入 $U$，时间复杂度 $O(|V|^2)$.

Kruskal 算法是，将初始图看成 $|V|$ 个独立的连通分量，每次选取权值最小的不会产生环的边（这可以用并查集维护），时间复杂度 $O(|E| \log |E|)$.

## 内排序
**内排序**即排序过程中所有的记录都可以直接存放在内存中的排序。如果存在多个具有相同排序码的记录，经过排序后这些记录的相对次序仍然保持不变，称这样的排序算法是稳定的。

插入排序略去，其主要时间消耗在于移动数据。不稳定的 Shell 排序先选择一个增量序列（从大到小的整数序列、最后一个增量是 1），对于某个增量 `gap`，将列表分成 `gap` 个子序列，每个子序列由间隔为 `gap` 的元素组成，分别对每个子序列插入排序；一直到增量 1 时对整个列表进行一次插入排序。对增量序列：Hibbard 序列 $\set{2^k - 1}$ 的最坏时间复杂度 $O(n^{3/2})$，Sedgewick 序列等更好但较复杂。

选择排序略去，其主要时间消耗在于没有利用之前的比较信息。不稳定的堆排序利用最大堆，时间复杂度 $O(n \log n)$.

冒泡排序略去。不稳定的快速排序是：从序列中选定一个值 $k$ 作为轴值（pivot），然后把小于 $k$ 的放在它左边，大于 $k$ 的放在它右边（维护下标 $l, r$ 同时往中间扫描，一边扫描到待移动元素时，另一边扫描直到扫描到待移动元素，将它们交换）

归并排序也是一种基于分治法的排序，但快速排序侧重“分”、归并排序侧重“合”。即：直接将序列划分为两个子序列，递归操作，然后合并。其副产物是逆序对计数。

易见只依赖于比较的排序算法最坏时间复杂度至少 $O(n \log n)$（判断树是二叉树、至少 $n!$ 个叶节点）。假定取值只有 $[0, m)$ 的整数则可以用桶排序。$m$ 较大时可以用基数排序，一般低位优先法较快。为了减少移动原数据的成本可以使用索引。
